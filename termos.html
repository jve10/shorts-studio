Termos de Uso — Shorts Studio

Última atualização: 9 de novembro de 2026.

1. O que é o Shorts Studio

O Shorts Studio é uma ferramenta de uso pessoal que roda no computador do próprio usuário. Ela corta e edita vídeos e, quando o usuário autoriza, envia os vídeos escolhidos para a conta do TikTok dele através da API oficial do TikTok (Content Posting API).

2. Conta do TikTok

A conexão com o TikTok é feita pelo login oficial do TikTok (Login Kit). O usuário pode revogar o acesso a qualquer momento pelo botão "Desconectar" no aplicativo ou nas configurações de segurança da conta do TikTok. Nenhum vídeo é publicado sem uma ação explícita do usuário.

3. Responsabilidade pelo conteúdo

O usuário é o único responsável pelos vídeos que publica e deve ter os direitos ou a autorização necessários para todo o conteúdo enviado, além de seguir as Diretrizes da Comunidade e os Termos de Serviço do TikTok.

4. Uso permitido

É proibido usar o Shorts Studio para publicar conteúdo ilegal, que infrinja direitos de terceiros, spam ou qualquer material que viole as regras do TikTok.

5. Sem garantias

O software é fornecido "como está", sem garantia de funcionamento contínuo ou de compatibilidade com mudanças futuras da API do TikTok.
