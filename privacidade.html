Política de Privacidade — Shorts Studio

Última atualização: 9 de novembro de 2026.

1. Onde os dados ficam

O Shorts Studio roda inteiramente no computador do usuário. Não existe servidor do Shorts Studio: nenhum dado é enviado ao desenvolvedor.

2. Dados do TikTok que o aplicativo usa

  • Informações básicas do perfil (nome de exibição, foto e identificador), para mostrar qual conta está conectada.
  • Token de acesso, guardado apenas em um arquivo no computador do usuário, para enviar os vídeos que ele escolher.
  • Permissões de postagem (opções de privacidade disponíveis, limites de duração), para montar a tela de publicação.

3. Para que os dados são usados

Exclusivamente para enviar ao TikTok os vídeos e legendas que o próprio usuário selecionar. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

4. Comunicação com terceiros

O aplicativo se comunica apenas com os servidores oficiais do TikTok (open.tiktokapis.com e tiktok.com) quando o usuário conecta a conta ou publica um vídeo.

5. Exclusão

O usuário pode apagar todos os dados a qualquer momento clicando em "Desconectar" no aplicativo (o token é revogado e o arquivo local é removido) ou removendo o acesso do aplicativo nas configurações da conta do TikTok.
